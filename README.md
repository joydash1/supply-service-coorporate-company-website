# SM Supply Services

A modern, responsive corporate website developed for **SM Supply Services**, a professional supply and distribution company providing quality products, reliable sourcing, and efficient supply solutions.

## 🚀 Project Overview

The website presents the company's products, services, company information, achievements, certificates, clients, and contact information through a clean and professional corporate interface.

The project focuses on a premium business-oriented design with responsive layouts, reusable components, modern UI elements, and an organized multi-page structure.

## ✨ Features

- Responsive corporate website
- Modern and professional UI design
- Dynamic Header and Footer components
- Home Hero section
- Product catalog
- Individual product details
- Company introduction
- Mission & Vision
- Achievements & Certificates
- PDF certificate viewer
- Client showcase
- Contact section and inquiry form
- Responsive mobile navigation
- Active navigation highlighting
- Reusable page sections
- SEO-friendly page structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- PDF.js
- Responsive Web Design
